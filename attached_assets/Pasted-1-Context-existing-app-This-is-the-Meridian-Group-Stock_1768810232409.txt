1. Context (existing app)

This is the Meridian Group – StockFix (Field Inventory Management) mobile/web app.

Current flow:

Login → I’m a Rep

Rep Visit Setup (Select Rep → Select Store → Start Visit)

Store Overview

Tasks screen (Pending | Completed)

Task Feedback screen (task execution & submission)

Important constraint
Tasks have ONLY TWO STATES:

Open (currently called Pending)

Completed

No other statuses exist.

2. Objective

Add new progress/monitoring screens that allow:

A Rep to see how they are tracking across all open and completed tasks, not only the current store.

A Manager to see team-wide task progress, compare reps, and identify backlog risk.

This should feel like a natural extension of the existing UI — same cards, colours, typography, buttons, and bottom navigation logic.

3. Navigation changes (minimal disruption)
Entry points

Icon style consistent with “View Tasks”

6. Task logic (critical – must match current app)

Open tasks = tasks shown under “Pending”

Completed tasks = tasks shown under “Completed”

Completion date = submit action timestamp from Task Feedback

Completion rate calculation:

Completed / (Open + Completed)


(using same filter scope)

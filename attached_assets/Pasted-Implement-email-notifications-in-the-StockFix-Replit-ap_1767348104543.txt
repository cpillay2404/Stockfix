Implement email notifications in the StockFix Replit app when a rep submits a task (clicks “Submit Action” on the Task Feedback page).

CRITICAL SCOPE RULES
- Do NOT change any UI layout, navigation, charts, image upload logic, or data model beyond what is required to trigger emails.
- Email sending must happen on the BACKEND (server/API), not in the browser.
- If email sending fails, the task submission must still succeed (log the error, do not block the user).

RECIPIENTS (hardcoded)
- Emails must ONLY be sent to:
  1) jjooste@meridiangroup.co.za
  2) cpillay@meridiangroup.co.za
- No other recipients, no CC/BCC, no dynamic routing.

TRIGGER CONDITIONS
- Send an email ONLY after the backend confirms the task submission has been saved successfully (DB/file write succeeded).

EMAIL PROVIDER
- Use SendGrid (preferred) via API key stored in Replit Secrets:
  - SENDGRID_API_KEY

- Also support a sender/from address via env var:
  - FROM_EMAIL (e.g., "stockfix@meridiangroup.co.za")
- If FROM_EMAIL is missing, fail gracefully with a clear server log message but do not block submission.

SUBJECT LINE (consistent for filtering)

- <STORE> = cleaned store name (e.g., CHECKERS FX ROBBERG BAY)
- <ACTION> = full Action Column text (no abbreviations)
